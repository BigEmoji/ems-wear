# Em's Wear 👖

A responsive e-commerce website built for Em's Wear, a fashion brand specializing in baggy jeans.

The project was built from scratch using HTML, CSS, and JavaScript, with a focus on responsive design, interactive shopping functionality, and a clean user experience.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Product catalog
- Product search
- Category filtering
- Product size selection
- Add to cart functionality
- Quantity controls
- Remove items from cart
- Cart total calculation
- Persistent cart using LocalStorage
- Dark/light mode
- Mobile navigation menu
- WhatsApp checkout
- Contact form validation
- Empty search-result state
- Accessible navigation controls

🛒 Shopping Cart

The shopping cart is built with JavaScript and uses LocalStorage to preserve cart data when the user refreshes or returns to the website.

Customers can:

Select a product size
Add the product to the cart
Increase or decrease quantity
Remove products
View the calculated total
Proceed to checkout through WhatsApp
